# Achantes — Vision

## ¿Qué es Achantes?

Achantes es una aplicación web social y creativa basada en salas privadas personalizables.

Cada usuario posee una única sala principal que funciona como una mezcla entre:

- habitación virtual
- collage interactivo
- muro personal
- espacio social privado
- listening room compartida

La experiencia está inspirada en:
- MySpace
- Tumblr
- cuartos adolescentes de los 2000
- estética caótica/personal del internet antiguo
- pizarras colaborativas
- habitaciones desordenadas de juegos de detectives clásicos

---

# Objetivo principal

El objetivo de Achantes es permitir que una persona invite amigos a "visitar su habitación virtual".

Dentro de esa habitación:
- pueden escuchar música sincronizada
- dibujar
- explorar imágenes
- compartir recuerdos
- ver PDFs
- interactuar con elementos del canvas
- comunicarse por chat
- dejar notas o grafitis

La sala debe sentirse:
- personal
- auténtica
- viva
- caótica
- emocional
- artesanal
- profundamente customizable

---

# Filosofía de diseño

Achantes NO debe sentirse como:
- una red social moderna genérica
- una interfaz corporativa
- una app minimalista fría

Debe sentirse como:
- entrar a la habitación real de alguien
- navegar un espacio íntimo y creativo
- descubrir detalles ocultos
- explorar un collage digital vivo

---

# Principios fundamentales

## 1. El canvas es el núcleo
Toda la experiencia gira alrededor del canvas interactivo.

## 2. El dueño controla la experiencia
La sala pertenece al dueño.
El dueño controla:
- música
- permisos
- persistencia
- estética
- módulos

## 3. El caos visual es parte de la identidad
La app debe permitir libertad visual extrema.

## 4. Los elementos deben integrarse visualmente
No deben sentirse como ventanas rígidas o dashboards tradicionales.

## 5. La música es central
La música sincronizada es uno de los pilares principales de la experiencia.

## 6. Todo debe sentirse manipulable
Mover, dibujar, pegar, superponer y organizar elementos debe ser natural.

---

# Modelo de acceso

Las salas NO son públicas.

El acceso ocurre mediante:
- invitaciones
- links temporales
- permisos definidos por el dueño

---

# Estado actual del proyecto

Actualmente:
- existe un canvas funcional
- existe sistema de imágenes y GIFs
- existe dibujo básico
- existe zoom y navegación
- existe organización básica de elementos

Prioridad actual:
- estabilizar arquitectura
- implementar música sincronizada
- mejorar sistema modular
- profesionalizar el canvas

---

# Meta MVP

La primera versión exitosa debe permitir:

1. Crear una sala
2. Decorarla libremente
3. Invitar a otra persona
4. Escuchar música sincronizada
5. Dibujar juntos
6. Explorar el espacio visual
7. Compartir imágenes/PDFs/notas

---

# Definición de éxito

Una versión exitosa de Achantes permite que dos personas en distintos países sientan que están compartiendo el mismo espacio digital.
